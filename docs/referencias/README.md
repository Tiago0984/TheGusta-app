# PDFs de referência

Cópias dos oito arquivos fornecidos pelo usuário. Os nomes e conteúdos originais foram preservados para que a implementação não dependa do OneDrive ou de caminhos de outro computador.

| Documento | Uso |
| --- | --- |
| [Atualizar foto perfil.pdf](<Atualizar foto perfil.pdf>) | Validação, captura/seleção e upload da foto |
| [Criar Conta - The Gusta - APP.pdf](<Criar Conta - The Gusta - APP.pdf>) | Cadastro e início da sessão |
| [Detalhe_Produto_Favoritos.pdf](Detalhe_Produto_Favoritos.pdf) | Favoritos no detalhe do produto |
| [Documentação Detalhes do Pedido.pdf](<Documentação Detalhes do Pedido.pdf>) | Consulta e apresentação do pedido real |
| [Documentação Tela de Pagamento.pdf](<Documentação Tela de Pagamento.pdf>) | Checkout e registro do pedido |
| [Documentação Tela Sacola.pdf](<Documentação Tela Sacola.pdf>) | Sacola persistente e dinâmica |
| [Favoritos_Cardapio e Home.pdf](<Favoritos_Cardapio e Home.pdf>) | Favoritos nas listagens |
| [Guia Esqueci a Senha e Redefinição.pdf](<Guia Esqueci a Senha e Redefinição.pdf>) | Código de verificação e redefinição |

Leia as diferenças entre os exemplos e o código atual no [plano](../plano-implementacao-pdfs.md). Os PDFs são material de referência; a solicitação atual e o progresso registrado definem o trabalho a executar.

O arquivo [manifesto-sha256.json](manifesto-sha256.json) registra tamanho e SHA-256 das cópias. Ele permite conferir se os arquivos chegaram íntegros ao outro computador.
